# ONE SEG Studio for Linux — Experimental Preview

**TEST BUILD — Ubuntu 26.04 LTS / amd64 (Intel or AMD 64-bit).**

The author has tested installation, HackRF operation and One-Seg reception on a Sony XDV-D500. This is an experimental preview, not a stable release or a certification of broadcast-standard compliance.

Download the complete installer archive attached to this release and extract it. Keep both `.deb` files, `INSTALL.sh`, `UBUNTU_VERSION` and `SHA256SUMS` together. Open a terminal in that folder and run:

```bash
bash INSTALL.sh
```

Internet and administrator access are required to install dependencies. No compilation is needed on the target computer. Open **ONE SEG Studio** from the desktop applications menu after installation.

The installer does not transmit RF. Check local frequency, power and authorization requirements before using Transmit. Users are responsible for their equipment's configuration and operation.

Other Linux releases and architectures have not been verified. The Linux preview interface is English only; camera input, integrated waveform display and guaranteed seamless looping are not included.
